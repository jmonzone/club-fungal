## Scheduling Rules
- Weekday sessions start after the last evening event (dinner or personal), capped at 11pm PT
- Weekend sessions are flexible, longer blocks available
- NYC/flight sessions are full productivity sessions

- Always check personal calendar AND meal plan before scheduling any session
- FEL (feel) tasks are interleaved throughout the schedule, not batched at the end

## Scheduling Workflow
When given playtest notes:
1. Parse notes into discrete system-level tasks
2. Check all three calendars for the next available slots
3. Present a proposed change list — new tasks with suggested dates/times — before doing anything
4. Wait for explicit approval ("yes", "approve", "go") before executing
5. On approval: delete any conflicting or outdated sessions, create new ones
6. Never execute calendar changes without approval
